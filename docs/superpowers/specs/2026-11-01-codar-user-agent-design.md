# Codar 模型请求 UA 设置

用户已确认使用 HAR 中包含 `codar-desktop/0.3.2` 的桌面端 UA。

设置页新增“请求转发”分组，包含默认开启的“使用 Codar UA”开关和可编辑 UA 文本框。默认值取自 `proxypin_2026-10-29.har` 中的桌面端请求。沿用现有设置保存、恢复默认和持久化机制，保存后新请求立即使用新值。

在模型请求完成解析、鉴权、选号并构造上游请求后，设置最终的 User-Agent，再经已选出口发送。适用于 Chat Completions、Responses、Messages、count_tokens、流式及非流式、重试、面板调用测试和模型目录请求。启用时统一使用配置值，不透传调用方的 UA。关闭时分别保留原有的 `Go-http-client/1.1` 或 `node` 行为。登录、签到、余额等账号接口不更改。

UA 去除首尾空白后不能为空，最多 1024 个可打印 ASCII 字符，拒绝换行和其他控制字符。无效设置整次拒绝，保留当前配置。开关关闭时保留编辑值，重新开启可继续使用。

验证包括各模型端点的流式和非流式实际 HTTP 请求头、设置热更新、关闭与重新开启、面板调用、模型目录与账号接口范围、非法输入和重载持久化，并运行现有 Go 测试及静态检查。界面按现有风格增加文本框，兼容窄屏，不需要截图。
