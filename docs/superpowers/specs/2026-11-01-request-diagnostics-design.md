# DSH 请求对照诊断

用户要求加入记录并重启本地面板，用于比较 DeepSeek harness 与已成功的 API Key 请求。保留现有转发和账号调度行为。

通过启动参数 `--request-diagnostics` 或环境变量 `CODAR_REQUEST_DIAGNOSTICS=true` 临时启用，默认关闭。数据目录中的 `request-diagnostics.jsonl` 按随机请求编号关联客户端请求头、解析后的原始 JSON、实际转发到上游的头和 JSON、每次上游状态与错误、流式解析后的最终结果及网关 HTTP 结果。参数日志在进入和转发两个阶段分别落盘，保留上游接受之前的失败现场。

敏感请求头、JSON 凭证字段、当前请求 Key、选中账号 token、JWT、Bearer 文本、常见 sk Key 及代理 URL 认证信息脱敏。对话和工具内容保留在本地，便于定位内容或结构差异。文件使用 0600 权限创建，不增加公共日志下载接口。日志同步追加，单条记录最多 16 MB，超过后保留脱敏前缀并明确标记截断；保留当前与一个轮换文件，每个约 64 MB。写入失败只记录服务日志，不中断业务。

诊断响应包装器支持 ResponseController 解包，保留 SSE 刷新和取消行为；仅收集有限的错误响应体，成功流不重复存储生成内容。记录入口在鉴权之前，鉴权失败也能关联诊断编号。重启只影响独立本地 Codar，不处理其他服务。
